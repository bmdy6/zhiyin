# 微信导出格式

知音只读取下面这份目录格式，不读微信数据库，也不需要密钥。[wechat-mac-export](https://github.com/bmdy6/wechat-mac-export) 的 `export` 和 `refresh_knowledge.py` 都会输出这种格式。用别的工具导出时，按这里的字段准备也能导入。

```text
导出目录/
├── 导出清单.json
├── 001/chat.jsonl
├── 002/chat.jsonl
└── 分组索引.json        # 可选
```

## 导出清单.json

```json
{"conversations": [
  {"sequence": 1, "conversation_id": "示例会话-A", "label": "示例备注", "folder": "001", "code": "A1"}
]}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `conversation_id` | 是 | 会话唯一标识，不能重复，用来在多次导入之间对上同一个人 |
| `label` | 是 | 显示用的备注名 |
| `folder` | 是 | 同目录下的子文件夹名，不能含路径分隔符 |
| `code` | 否 | 代号。缺省时用 `A{sequence}`，规则和 `refresh_knowledge.py` 一致 |
| `sequence` | 缺 `code` 时必填 | 整数编号 |
| `relationship` | 否 | `家人`、`朋友`、`同事`、`办事`、`其他`、`未分类`，缺省为 `未分类` |
| `groups` | 否 | 分组名列表，作为上下文元数据 |

其他字段（如 `count`、`first`、`last`）会被忽略。

## chat.jsonl

每行一条消息，按时间排列：

```json
{"time": "2026-01-01T09:00:00+00:00", "sender": "them", "type": 1, "subtype": null, "text": "示例消息"}
```

| 字段 | 说明 |
| --- | --- |
| `time` | ISO 8601 时间。没有时区时按 UTC+8 处理 |
| `sender` | `me` 或 `them`。系统消息（`type` 为 10000 或 10002）可以是 `unknown` |
| `type` | 微信消息类型，整数。`1` 是文本 |
| `subtype` | 整数或 `null`。`type=49, subtype=57` 是引用回复 |
| `text` | 字符串。非文本消息可以是占位符 |

其他字段（如 `local_id`、`server_id`、`shard`）会被忽略。导入按会话、时间、方向、类型和内容去重，同一份快照或扩充后的快照可以重复导入。

两边任一方改动这份格式时，同步更新本文和 `tests/test_wechat.py`。
